# Правила для агента

Сначала прочитай `docs/spec.md`. Не переписывай работающий код без причины. Этапы 1–6 первой версии уже сделаны. Практическая установка и раздача копии описаны в `README.md`.

- Не выдумывай селекторы, URL и ответы сайта. Живое чтение сейчас есть только для `https://stud.ibnd.ru`. Для другого сайта нужен обезличенный образец из раздела 7 `docs/owner.md`.
- Не проси пароль, cookies, токены кабинета, HAR с авторизацией и доступ к Google-аккаунту. Настройку Google пользователь делает сам по `README.md`.
- Не начинай версию из `docs/roadmap.md`, пока её явно не попросили, и не начинай следующую, пока текущая не принята.
- `docs/future.md` не реализовывать без отдельной просьбы. Выбор типа пары остаётся только там. Другие сайты, если их попросили как версию 0.9, делаются по `docs/roadmap.md`.
- После этапа, который меняет код, сборку или поведение, обнови `docs/status.md` по правилу `.cursor/rules/project-status.mdc`. В статус не пиши токены, пароли, cookies, HAR, фамилии, адреса встреч и полный текст расписания.
- Вопрос без изменений в проекте файл статуса не меняет.
